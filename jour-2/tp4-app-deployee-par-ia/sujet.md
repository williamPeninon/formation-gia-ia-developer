# TP4 — Application déployée par IA

## Pourquoi ce TP n'a pas de dossier depart/corrige de code

Ce TP consiste à construire une application **uniquement via un outil
d'assistance IA** (Bolt, Lovable, ou le mode agent de GitHub Copilot) :
il n'y a donc pas de code de départ à fournir, ni de correction "code"
à proprement parler — l'évaluation porte sur la démarche et le résultat
déployé.

## Consignes

1. Choisir un outil : [Bolt](https://bolt.new), [Lovable](https://lovable.dev)
   ou le mode agent de GitHub Copilot.
2. Développer une application web répondant à un besoin simple (à définir
   avec le formateur, ou au choix du participant) **sans écrire de code
   à la main** : uniquement des prompts et des ajustements via l'outil.
3. Déployer l'application (déploiement généralement intégré à l'outil).
4. Vérifier que l'application déployée est accessible via une URL
   publique.

## Éléments à documenter pendant le TP

- Le prompt initial utilisé
- Les 2-3 principaux prompts de modification/itération
- L'URL de l'application déployée
- Un point de vigilance observé (coût, quota, code généré à relire...)

## Éléments de réponse

Voir le Guide formateur, module 4, TP4 — la grille d'évaluation y est
détaillée (qualité de la démarche, couverture du prompt initial,
usage pertinent des prompts de modification).
