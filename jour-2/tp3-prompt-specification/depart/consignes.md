# TP3 — Prompt de spécification

## Contexte

Rédiger un **prompt de spécification** (pas de code) pour une application
web qui affiche les nouvelles positives du jour.

## Consignes

1. Le prompt doit préciser :
   - les sources d'information à utiliser (ou à imaginer),
   - le critère permettant de qualifier une nouvelle de « positive »,
   - le ton éditorial attendu,
   - la structure de la page attendue,
   - le format de sortie souhaité pour la réponse du LLM.
2. Appliquer au moins **deux techniques** vues en cours parmi :
   Role Prompting, Few-Shot Prompting, Chain-of-Thought, format de sortie
   explicite, itération.
3. Rédigez votre prompt dans le fichier `mon-prompt.md` de ce dossier.
4. Testez-le avec le LLM de votre choix et notez si le résultat correspond
   à vos attentes — sinon, itérez sur le prompt.

## Rendu attendu

Un fichier `mon-prompt.md` contenant votre prompt final, prêt à être
partagé lors de la correction collective.
