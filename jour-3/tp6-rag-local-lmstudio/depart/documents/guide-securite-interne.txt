Guide de sécurité informatique interne — Entreprise fictive Ascentia

Mots de passe : longueur minimale de 12 caractères, renouvellement tous
les 90 jours, interdiction de réutiliser les 5 derniers mots de passe.
L'authentification à deux facteurs (2FA) est obligatoire pour tous les
accès aux outils internes (messagerie, VPN, outils RH, dépôts de code).

Postes de travail : chiffrement du disque activé par défaut, verrouillage
automatique de session après 5 minutes d'inactivité, mise à jour de
sécurité automatique tous les mardis soir.

Données confidentielles : toute donnée client ou document interne
classifié "confidentiel" ne doit jamais être envoyé à un service cloud
externe non validé par la DSI (y compris les outils d'IA grand public).
Pour les cas d'usage IA sur des données sensibles, utiliser exclusivement
les solutions locales validées (LM Studio avec modèles approuvés).

Incidents : tout soupçon de compromission (phishing, perte de matériel,
accès suspect) doit être signalé dans l'heure à securite@ascentia.example
via le formulaire d'incident interne.
